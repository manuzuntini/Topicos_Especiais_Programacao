# 📘 Documentação das Aulas - Tópicos Especiais em Programação

Este repositório contém a documentação das aulas 1 a 10 da disciplina **Tópicos Especiais em Programação**. Cada pasta representa uma aula específica e está organizada conforme a estrutura abaixo:

## 📂 Estrutura do Repositório

- 📁 **Aula 1** - Introdução aos Conceitos de Programação Avançada
- 📁 **Aula 2** - Configuração de Ambiente e Ferramentas de Desenvolvimento
- 📁 **Aula 3** - Noções de Automação e Fluxos Básicos
- 📁 **Aula 4** - Integração com APIs e Manipulação de Dados
- 📁 **Aula 5** - Criação de Agentes Inteligentes e Suas Aplicações
- 📁 **Aula 6** - Fluxos com Langflow: Agentes Inteligentes para Notícias e Humor
- 📁 **Aula 7** - Instalação do Dify e Introdução a Chatbots com Base de Conhecimento
- 📁 **Aula 8** - Fluxo de Atendimento para Revenda, Utilizando JSON Schema
- 📁 **Aula 9** - Implementação de Chatbot para Agendamentos com API do Cal.com
- 📁 **Aula 10** - Instalação de APIs de WhatsApp e Configuração de Automação

## ℹ️ Sobre a Disciplina

**Tópicos Especiais em Programação** explora ferramentas e técnicas avançadas, focando em agentes inteligentes, automação e integração de APIs. Através de exercícios práticos, os alunos aprendem a desenvolver sistemas autônomos e eficientes para solucionar problemas reais.
